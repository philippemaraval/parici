Historique des corrections

Les modifications apparaissent dans les collections, profils et prochaines parties. Vider un champ rétablit son contenu automatique.

Fragments

Sans fragments : carte directe (0 fragment). Avec fragments : placement correct → QCM culturel → bonne réponse = +1 fragment ; mauvaise réponse = aucun fragment. Les questions tournent pour éviter les répétitions. Quatre réponses distinctes et une explication sont requises. Une question déjà présentée reste inchangée pour le joueur. Chaque nouvel exemplaire nécessite un nouveau cycle de fragments.
